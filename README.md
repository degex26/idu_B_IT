# 🚀 IDU B IT — From AnyKey to DevOps

> **Мой первый DevOps-проект:** веб-приложение на Python + Flask, запущенное в Docker на локальном Ubuntu-сервере (VMware).

---

## 📋 О проекте

Этот проект — мой учебный стенд для отработки навыков DevOps.  
Здесь я применяю:

- 🐍 **Python** + **Flask** для написания веб-приложения  
- 🐳 **Docker** для контейнеризации  
- 🐧 **Ubuntu Server** (в VMware) как тестовую среду  
- 🔐 **Git + GitHub** для контроля версий и портфолио  
- 🚀 **GitHub Actions** (настроен, но пока используется локальный деплой)  

---

## 🎯 Цель проекта

Показать путь от **AnyKey (сисадмин)** до **DevOps-инженера** через реальный пет-проект.

---
