# 🖥️ IDU B IT — стенд

> **Мой первый DevOps-проект:** веб-приложение на Python + Flask, запущенное в Docker на домашнем сервере (VMware + Ubuntu).

---

## 📋 О проекте

Этот проект — мой учебный стенд для отработки навыков DevOps.  
Здесь я применяю:

- 🐍 **Python** + **Flask** для написания веб-приложения  
- 🐳 **Docker** для контейнеризации  
- 🐧 **Ubuntu Server** (в VMware) как тестовую среду  
- 🔐 **Git + GitHub** для контроля версий и портфолио  
- 🚀 **GitHub Actions** (планируется) для CI/CD
